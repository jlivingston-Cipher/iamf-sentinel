# Support

This project — the `iamf-sentinel` core, the `iamf-sentinel-pro` plugin, the
`sentinel-dsp` kernel, and the `iamf-loom` packager — is free software
(Apache-2.0) maintained **best-effort by a single maintainer**.

What that means in practice:

- **Bug reports** with a reproducible file or fixture are welcome and will be
  looked at; a clear conformance question with a check ID (`S-xxx`) gets the
  fastest answer.
- **No SLA** is offered or implied. Response times vary with maintainer
  availability. Feature requests may be declined to keep the check registry
  and the CI contract stable.
- **Security / disclosure**: issues in the reference implementations found by
  this project's tooling are reported upstream through the AOM process; issues
  in this project itself can be reported privately to the maintainer.
- **Commercial support, integration help, and consulting are available** —
  engagements are accepted case-by-case (CI integration, platform profile
  work, ADM→IAMF pipeline QC, custom checks). Contact the maintainer via the
  [`jlivingston-Cipher`](https://github.com/jlivingston-Cipher) GitHub
  profile: open an issue for anything public, or use the profile's contact
  links for engagement inquiries.
